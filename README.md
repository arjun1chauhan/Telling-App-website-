# Telling: Confess & Chat – Website

An interactive, single-page website that showcases the features and benefits of the **Telling: Confess & Chat** Android app by Nikola Studios.

App on Google Play: https://play.google.com/store/apps/details?id=com.telling.social

## What's inside
- `index.html`: the complete site (HTML, CSS and JavaScript in one file, no build step)

## Features shown
Anonymous confessions, random public chat rooms, new friends, following users, real-time messaging, room creator controls, banning users, deleting rooms, a simple interface and a safe community. The page includes a working phone demo.

## Run locally
Open `index.html` in any browser.

## Host with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
